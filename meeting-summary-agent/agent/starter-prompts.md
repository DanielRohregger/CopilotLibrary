# Starter prompts

Use a compact selection in the published agent. Each prompt can be copied independently.

## Standard summary

```text
Summarize the uploaded meeting transcript.
```

## Detailed minutes

```text
Create detailed meeting minutes with decisions and action items.
```

## Action items

```text
Extract all actions, owners, deadlines, blockers, and dependencies.
```

## Decision log

```text
Create a decision log from the uploaded transcript.
```

## Risks and blockers

```text
Identify the risks, current issues, blockers, and dependencies discussed in this meeting.
```

## Next steps

```text
Separate the agreed next steps from your recommended next steps.
```

## Follow-up email

```text
Create a professional follow-up email for the meeting participants.
```

## Management summary

```text
Create a concise management summary focused on outcomes, decisions, risks, and required actions.
```
