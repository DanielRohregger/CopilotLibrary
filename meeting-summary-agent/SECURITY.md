# Security and responsible use

## Reporting

Do not publish real meeting transcripts, credentials, personal data, customer data, or confidential information in GitHub issues or pull requests. Report repository security concerns privately to the repository owner.

## Data handling

This package contains templates only. Meeting transcripts must not be committed to the repository unless they are synthetic and approved for public use.

Organizations are responsible for assessing:

- Transcript confidentiality
- Personal and sensitive information
- Data-processing and retention requirements
- Access and sharing policies
- Works council requirements
- Appropriate human review

The included example transcript is synthetic.
